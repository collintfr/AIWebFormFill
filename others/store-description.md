# Proposed version 2 store description

Review saved values before filling Firefox forms. Your profile lives in a
passphrase-encrypted local vault. Exact alias matching and manual selection work
offline; an optional one-time model download enables local AI similarity matching
through Transformers.js. No AI server or automatic focus suggestions are used.

Approve the sites you use, open a field or form preview, inspect the destination
and proposed values, then choose what to fill. Third-party embedded forms require
separate destination approval. Values become visible to the website after insertion.

Backups are encrypted only. Lock and clear-all controls manage the extension's
stored data. Keep your passphrase safe: there is no password recovery. Clearing
extension storage cannot erase previously exported files or browser backups.

This text is prepared for publication; the existing store listing has not been changed.
