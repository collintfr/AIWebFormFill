AI Form Fill

Preview first. Fill only what you approve. Matching runs on your device.

Encrypted vault

Your passphrase is never saved. Use at least 12 characters. There is no password recovery. Closing the browser or suspending the background may require unlocking again.

Groups, records, and attributes

Create one record for each degree or job. Identical school names can belong to separate records. Use nested records for majors and other repeated details. Attribute names and aliases match page fields. Changes are saved only when you click Save.

The education template includes location, study level, degree, GPA and scale, class rank/size, two majors, two minors, separate start/end/graduation months and years, and an Awards text field. Type all your awards directly into that field, using multiple lines if needed. Enter month names for dropdowns; optional full dates use YYYY-MM-DD. Include the related records you want in each fill preview. Main values, additional attributes, and related details have separate sections; expand Field aliases or Manage only when needed.

Encrypted backups contain your encrypted profile. Plaintext files are not supported. Import replaces the current vault after authentication.

Deletion covers extension storage and caches. Earlier files, clipboard history, browser backups, and copies on other synced devices remain outside this extension.

Local matching model

A fixed quantized MiniLM embedding model matches fields to your aliases. Setup downloads public model files from Hugging Face and its asset hosts. No profile or page metadata is sent. Matching then works offline.

Approved destinations

Approve each destination before use, then reload its page and right-click an empty visible field. Embedded third-party forms need separate destination permission and approval in each preview.
